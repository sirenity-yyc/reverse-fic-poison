Fic Cleaner

Antidote for fic-poison — paste your HTML, get clean text back

Everything runs in your browser. Your fic never leaves your device.

▶ How does this work?

The fic-poison script injects junk text into AO3 fanfiction HTML to disrupt AI training scrapers. It hides the garbage from human readers using CSS workskins, but scrapers doing raw text extraction pick it all up.

It has two modes. Tame mode inserts whole paragraphs of random words as <p class="poison"> blocks between your real paragraphs. Default mode is sneakier — it threads single junk words throughout the text inside <span> tags, and uses a zero-width space character to break the HTML tag so browsers don't even parse it.

This tool runs three regex passes: it strips the tame-mode paragraphs, strips the default-mode spans (with or without the zero-width space trick), and sweeps up any stray zero-width spaces left behind. It handles both modes at once — you don't need to know which one was used.

If the author used a custom class name instead of poison, change the class field above to match. You can find it by searching the HTML for class="something" on tags containing random words.
